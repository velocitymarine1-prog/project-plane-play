# Project Plane · the playable prototype

Level 1, THE HOUSE IN ONE. Throw a paper plane through a comic-book house; every throw pays; buy a better arm and a better plane until the
house falls in one throw. Built for a phone in portrait: drag the plane back, swipe forward.

Play: https://velocitymarine1-prog.github.io/project-plane-play/

This repository holds only the browser files of the build (the kit vendored from the COMIC 3D house style, the level, the game). The design
passes, the solvers and the source of truth live in the private `project-plane` repository; this copy is written by its `tools/deploy.sh`
from commit `212dd7e`.
