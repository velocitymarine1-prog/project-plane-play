# Project Plane · the playable prototype

Six levels: THE HOUSE, then THE SCHOOL, THE GROCERY STORE, THE SHOPPING MALL, THE ZOO and THE FACTORY (the five as greybox until their pieces
cards). Throw a paper plane through a comic-book place; every throw pays; buy a better arm and a better plane until the place falls in one
throw; finish a level to open the next. Built for a phone in portrait: drag the plane back, swipe forward.

Play: https://velocitymarine1-prog.github.io/project-plane-play/

This repository holds only the browser files of the build (the kit vendored from the COMIC 3D house style, the level, the game). The design
passes, the solvers and the source of truth live in the private `project-plane` repository; this copy is written by its `tools/deploy.sh`
from commit `76f7880`.
